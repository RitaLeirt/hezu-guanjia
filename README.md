# 🏠 合租生活管家

合租场景的一站式生活协作中心：把算不清的账、排不明的班、记不住的物、说好的规矩，全部透明化、可视化、可提醒。

## 功能模块
- **💰 费用 AA 分摊**：多分类账本、垫付记账、均摊/自定义分摊、智能结算（自动算出「谁欠谁」）、月度报表。
- **🧹 清洁值日排班**：任务清单、按室友顺序循环生成轮值表、完成/调班/略过、临近到期高亮提醒。
- **🛒 公共物品登记**：物品台账、库存进度条、低于阈值自动「补货提醒」、消耗/补货记录。
- **📜 室友公约**：条款管理、成员逐条「已同意」确认、模板一键填入。
- **📊 概览**：本月支出、待结清金额、待办清洁、待补货物品一屏掌握。

## 技术说明
- 纯前端静态站点（HTML + CSS + 原生 JS），无需后端。
- 数据使用浏览器 `localStorage` 存储，首次进入自动载入演示数据（阳光合租屋 / 小明·小红·阿强）。
- 适合作为产品原型 / 面试演示；多端实时协作需接入云端数据库（如 CloudBase NoSQL）。
